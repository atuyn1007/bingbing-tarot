# 万象归一阵第一阶段设计

## 目标与边界

本阶段只完成：选择牌阵 → 万象归一阵介绍页 → 输入问题 → 开始起卦 → 第一轮初爻静态牌背。

明确不实现：洗牌、选牌、翻牌、随机牌序、正逆位、第二至第六轮、6/7/8/9、阴阳、本卦、动爻、变卦、易经内容、解读、历史记录或数据库写入。

## 入口与牌阵数据

在现有 `SPREAD_OPTIONS` 增加 `unity`：

- 名称：万象归一阵
- 英文名：The Unity of All Things
- 牌数：18 张
- 解读时长：15–25 分钟
- 适合情境：人生节点、长期方向、重大决策与复杂议题
- 简介说明十八张塔罗、六轮起卦及未来会结合传统六爻，但不展示未实现结果。

选择页彻底移除所有语言数据中的 `difficulty` 和 `metaDifficulty`。所有牌阵只展示名称、英文名、简介、牌数、建议解读时长与适合情境。

第四张卡复用旧纸、黑金、档案编号、星轨和天文刻线。它以六层轨道、十八枚档案刻点和更强的馆藏主件层级区别于三个普通牌阵，不引入新视觉系统。

## 页面与状态

`App.jsx` 仅增加两个页面状态：

- `unity-intro`：独立介绍和问题输入页；
- `unity-casting`：第一轮初爻静态占位页。

新增 `unityQuestion` 保存用户输入。语言切换只重新渲染文案，不清空问题或改变当前页面。

选择 `unity` 时不进入普通 `DrawingPage`，而是进入 `unity-intro`。普通三种牌阵和真人解牌流程不变。

## 介绍页

新增聚焦组件 `UnityIntroPage.jsx`，沿用黑色天文舞台与旧纸问题卷宗，包含：

- 万象归一阵 / THE UNITY OF ALL THINGS；
- “天人感应，顺势而为。天生万物，境随心变。”；
- “本阵以十八张塔罗映照六爻之象。六轮起卦，每轮三张牌，最终形成完整卦象。”；
- 问题输入与提示“请专注于一个值得认真面对的问题。”；
- “开始起卦”按钮。

空白或纯空格问题不能继续，按钮说明缺少问题；问题只做 `trim` 验证，不设置过短上限。

## 第一轮页面

新增 `UnityCastingPage.jsx`，只显示：

- 第一轮 · 初爻；
- 三张未翻开的塔罗牌背；
- 克制的阶段说明与返回首页操作。

三张牌背必须是无交互的展示元素：不用 `button`，不设置 `tabIndex`、点击或键盘处理，不调用 `createDrawSession`，不生成牌 ID、正逆位或随机数据。装饰性牌背对辅助技术隐藏，页面另有可读的阶段标题。

## 国际化与兼容

新增文案全部进入现有 `zh-CN`、`en`、`it` 结构。逻辑只使用 `spread.key === 'unity'`，不通过中文字符串判断。

不导入或调用 `unitySpread.js`、`UnityResultPage.jsx`、算法、知识库或解释引擎；不修改 Supabase 表或现有持久化接口。

## 验收与测试

- 选择页有四个牌阵，且代码和三种语言均无难度字段。
- 万象归一显示 18 张、15–25 分钟与规定情境。
- 点击入口只进入介绍页；空问题无法继续。
- 输入问题后进入 `unity-casting`，只显示第一轮初爻与三张静态牌背。
- 静态牌背不可点击、不可聚焦，不生成任何抽牌或卦象数据。
- 普通三种牌阵、真人解牌、语言切换不回归。
- `npm test`、`npm run build` 通过；360、768、1024、1440px 无横向溢出或不可用布局。
