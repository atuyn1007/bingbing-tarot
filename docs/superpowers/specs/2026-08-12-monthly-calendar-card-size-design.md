# 本月日历牌面放大设计

## 目标

放大“本月日历”各日期格中的已抽牌正面、无图片回退牌背和未抽日期占位牌背，使牌面内容在桌面端更容易辨认，同时保持移动端七列日历完整可用。

## 范围

- 只修改 `src/solar.css` 中 `monthly-calendar-*` 相关响应式尺寸。
- 已抽牌图片、图片缺失回退牌背、未来/错过日期占位牌背使用一致的视觉尺寸。
- 不修改日历数据、打开详情的交互、日期状态、文案、Supabase 或“万象归一”代码。

## 尺寸方案

- 桌面端：牌面高度由约 32–40px 提升到约 54–64px；牌背宽高同步放大，保持塔罗牌纵横比例。
- 768px 以下：牌面高度约 36–40px，牌背同步放大；保留日期编号和 Today 标签空间。
- 390px 以下：维持七列与现有间距，不继续扩大单元格；牌面不得横向溢出或覆盖日期信息。

## 验收

- 正面与牌背在同一断点下视觉尺寸一致。
- 360px、768px 与桌面宽度均保持七列、不横向溢出。
- 已完成日期仍可点击打开档案；正逆位旋转不受影响。
- `npm test` 与 `npm run build` 通过。
