# 四季牌阵

## 已确认的产品规则

- 平时也能抽，不限制日期或次数；提示推荐在春分、夏至、秋分、冬至使用。
- 阅读范围为接下来三个月，不写死年份或节气日期。
- 五组各一张，顺序：大阿尔卡纳、宝剑、权杖、圣杯、星币。各花色包含 10 张数字牌和 4 张宫廷牌，无额外指示牌。
- 十字布局：中央大阿尔卡纳，上星币、右宝剑、左权杖、下圣杯。
- 沿用现有洗牌、拖动牌带、取消选择、确认、逐张翻牌、全部翻开和解读交互。每组确认一张，再进入下一组。
- 78 张牌在创建会话时完成随机排序与正逆位分配，各组使用该冻结牌序中的对应索引。选牌、翻牌和查看历史不重新随机。
- 五组全部确认后，沿用普通塔罗历史保存流程；不保存未完成牌阵，不修改 Supabase 表。普通塔罗历史仍沿用原有本地最近三条保留策略。
- 季度综合解读使用现有正逆位牌义档案，先读中央，再将每张小阿尔卡纳联系中央，最后汇总五个位置；不将职业问题模板套到整个生活牌阵。

## 资料核对（2026-09-23）

通过 Agent Reach 的 Exa 搜索和 Jina 网页阅读核对。下列内容是资料，不是产品授权或必须照搬的规则。

1. [西柚 Theo：四季牌阵到底是什么？怎么读？](https://mancytheo.com/the-four-seasons-spread/)：全文核对。明确五组各一张、中央大阿尔卡纳优先解读、其他牌联系季度主题；文中说明洗牌抽牌顺序可能不同。文章引用 Marcia Masino 的书籍，但本次未独立核对原书，不据此宣称唯一历史来源。
2. [塔罗网：四季牌阵怎么抽、怎么解](http://www.taluo5.com/jiaocheng/202510083917.html)：搜索摘要支持五组组成及先整体、再四元素联动的解读方式。
3. [占星网：塔罗四季牌阵及解法](https://nayona.cn/1548.html)：搜索摘要支持左权杖、下圣杯、右宝剑、上星币的布局。

资料有仅限四个节气、抽取顺序不同、增设宫廷牌组等变体；本功能遵循用户确认的不限日期、五张牌和明确抽取顺序。没有引入应期预测、月相推算或额外牌组。未复制外站牌义、案例或配图。
